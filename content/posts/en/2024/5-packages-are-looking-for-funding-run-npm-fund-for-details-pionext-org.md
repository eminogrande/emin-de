# NPM Fund: Continuous Token Markets for Open Source Funding

## Core Concept

NPM Fund creates an automated, continuous token market for open source packages, inspired by:
- Curation Markets: Token-based value attribution for content/projects
- Bonding Curves: Automated price discovery and continuous liquidity
- pump.fun's token launch mechanism: Fair, bot-resistant token distribution

The key innovation is combining these mechanisms with npm's existing funding infrastructure (`npm fund`) to create perpetual funding streams for open source maintainers.

## Mechanism Design

### Continuous Bonding Curves

Unlike traditional token launches or DEX markets, each package's token exists in a continuous state of potential minting or burning. The system:
- Has no maximum supply
- Never stops offering tokens
- Always provides buy/sell liquidity
- Requires no external market makers
- Maintains continuous price discovery

This creates an "endless curve" where:
1. Anyone can mint new tokens at any time
2. Anyone can burn tokens for the underlying asset at any time
3. Price adjusts automatically based on supply
4. Liquidity is mathematically guaranteed

### Key Differences from Traditional Markets

Traditional Token Launch:
- Fixed supply
- Limited initial distribution
- Requires DEX liquidity
- Vulnerable to manipulation
- Front-running risks

NPM Fund's Continuous Market:
- Unlimited supply potential
- Perpetual availability
- Built-in liquidity
- Manipulation resistant
- Predictable pricing

### Economic Principles

The system leverages three key economic mechanisms:

1. **Value Capture**
 - Maintainers receive 21% of all token interactions
 - Fee distribution is automatic and continuous
 - No need for grant applications or sponsorships

2. **Price Discovery**
 - Price increases with supply
 - Early supporters get better prices
 - Market sentiment directly reflected in price

3. **Liquidity Guarantee**
 - Bonding curve always holds collateral
 - Exit liquidity always available
 - No reliance on external market makers
